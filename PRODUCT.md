A personal portfolio website that authentically showcases Dimas Rizky AF's 4+ years of professional game development experience, published titles across Steam, Android, and iOS, core technical architecture skills, and official industry credentials.

"Unity Lead Game Developer & Game Programmer" specializing in scalable MVP/VContainer architecture, real-time multiplayer netcode (AWS GameLift, Unity Netcode, Photon), custom package engineering, and mobile performance optimization.

- **Stack**: Pure Vanilla HTML5, CSS3 (Custom HUD Design System), and JavaScript (ES6+ Classes).

- **Constraint**: Static file architecture (zero backend requirement), deployed on static hosting (GitHub Pages, Netlify, Vercel).
- **Design Philosophy**: Cyberpunk Game HUD aesthetic; content remains the primary focus; animations serve a clear purpose (scroll reveal, state change) rather than excessive decoration.
